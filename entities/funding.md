# Funding — the constellation's money picture

One page for grants / hackathons / awards across all four projects, because the
applications deliberately do NOT overlap: each ask is scoped to one project so they
never compete for the same story. Application/correspondence *drafts* stay private in
each repo (e.g. hestia's gitignored `outreach/`); this page is the cross-project ledger.

## Principles

- One project per application; the pitch leads with the story only that project can
  tell (hestia = unplug Alexa; forager = species ID with abstention on a pocket NPU).
- The [[hestia]] concierge/retainer idea may appear in *private* funding correspondence
  as the sustainability story, but never in a public repo (see hestia STRATEGY-PRIVATE.md).
- Hackathon winnings are earmarked: hestia's NAS/bulk-storage plan is gated on them.
